## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (≥ 3.47.1)
- [Dart SDK](https://dart.dev/get-dart) (≥ 3.13.1)

### Running a Dart Console App (Assignments 1–2)
```bash
cd assignment_1  # or assignment_2
dart run lib/main.dart
```

### Running a Flutter App (Assignments 3–8)
```bash
cd assignment_5  # or any Flutter assignment folder
flutter pub get
flutter run -d chrome   # or: flutter run -d macos
```

### Running Tests (Assignments 5 & 8)
```bash
cd assignment_5  # or assignment_8
flutter test
```
